# Arduino Temperature Sensor (Proteus Simulation)

##  Description
This project is an Arduino-based temperature monitoring system designed and simulated using Proteus. It reads temperature data from a sensor and displays it in real time.

##  Components
- Arduino Uno
- Temperature sensor (LM35 / DHT11)
- LCD / Serial Monitor
- Proteus simulation

##  Features
- Real-time temperature reading
- Simple and efficient design
- Fully simulated in Proteus

##  How to use
1. Open the project in Proteus
2. Run the simulation
3. Observe temperature values on display
